# Skill 08 — Creative & message testing

Keep a continuous, structured test pipeline so creative never goes stale.

## Output
`campaigns/creative-tests.md` — a running table: test ID, channel, hypothesis, variants, start date, result, learning.

## Steps
1. Pick one variable per test: angle, hook/headline, format (video / document / single image), CTA or offer.
2. Draft variants from the messaging angles in the market analysis, following `config/brand-voice.md`. Only approved claims.
3. Write the hypothesis and success metric (CTR for hooks; CPL / SQL rate for offers).
4. Submit for approval (as a change-request item).
5. After minimum data (see `config/kpis.md`), call the result, retire the loser, record the learning.
6. Watch for fatigue: CTR down > 30% from a creative's first-14-day average, or LinkedIn frequency > 4/month → refresh.
